# General Class Study Guide — narration rules and vocabulary
#
# Reference for preparing text before it is sent to text-to-speech.
# The MP3s use a self-hosted Open Speech server, voice "will"
# (am_puck(1)+am_liam(1)+am_onyx(0.5) at 1.1x speed), MP3 output.
#
# ---------------------------------------------------------------------
# NARRATION RULES
# ---------------------------------------------------------------------
# Sources
# - Subelement narratives and question banks: subelements/*.md
# - Cram sheet: read tts/CRAM-SHEET-audio.md (the narration script), not
#   CRAM-SHEET.md. Keep the two in agreement.
# - Technician refresher: TECHNICIAN-BRIDGE.md
#
# Question banks
# - Read each question as: "Question G1A01." the question, each choice
#   ("A. ..."), then "The correct answer is B. <answer>." then the
#   explanation. Say each group heading before its first question.
#
# Layout
# - Tables: read each row as a sentence. Two columns: "cell 1: cell 2."
#   More columns: "Header 1: cell. Header 2: cell. ..."
# - Headings and list items end with a full stop so the voice pauses.
# - Drop horizontal rules, images, links (keep link text), emoji, and
#   markdown emphasis.
#
# Formulas and math
# - "=" -> "equals"; "+" -> "plus"; "−" -> "minus"; "×" -> "times";
#   "a/b" -> "a over b"; "<" / ">" -> "less than" / "greater than"
# - Subscripts: X_L -> "X L"; R₁ -> "R 1"; V_pp -> "V peak to peak"
# - Implicit products: 2πfL -> "2 pi f L"; I²R -> "I squared R"
# - √ -> "the square root of"; ² -> "squared"; ^ -> "to the power of"
# - ≈ -> "approximately"; ± -> "plus or minus"; ° -> "degrees";
#   λ -> "wavelength"; → -> a comma pause; ~65% -> "about 65%"
# - Common fractions in words: 1/2 one half, 1/4 one quarter,
#   3/4 three quarters, 2/3 two thirds, 5/8 five eighths, 1/10 one tenth
# - Ranges: 3.800–4.000 -> "3.800 to 4.000"; ratios: 4:1 -> "4 to 1"
# - Units after numbers: 15A amps, 2000V volts, 1500W watts, 60 km
#   kilometers, 100 ft feet; Ω ohms, kΩ kilohms, μF microfarads,
#   pF picofarads, nF nanofarads, mH millihenrys
# - Slashes that aren't division: I/Q "I and Q", T/R "transmit receive",
#   USB/LSB "USB or LSB", 75/80m "75 and 80 meter", /AG "stroke A G"
#
