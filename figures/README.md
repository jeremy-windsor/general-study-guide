# Figures

Circuit diagrams, schematic symbols, and antenna radiation pattern references for the General class question pool.

## Schematic Symbols

- **[G7-1-schematic-symbols.svg](G7-1-schematic-symbols.svg)** — Figure G7-1, redrawn from the official NCVEC figure ([G7-1.pdf](https://www.ncvec.org/downloads/G7-1.pdf)) with the same circuit and numbering: a JFET oscillator driving an NPN stage, with 11 numbered parts (1 N-channel JFET, 2 NPN transistor, 3 diode, 4 varactor diode, 5 Zener diode, 6 iron-core transformer, 7 tapped inductor, 8 capacitor, 9 resistor, 10 capacitor, 11 potentiometer). Like the exam figure, the drawing has no parts key, because the study app shows it with questions G7A09–G7A13.

## Antenna Radiation Patterns (G9)

- **[G9-dipole-radiation-pattern.svg](G9-dipole-radiation-pattern.svg)** — Half-wave dipole figure-8 pattern. Maximum broadside, nulls off ends.
- **[G9-vertical-radiation-pattern.svg](G9-vertical-radiation-pattern.svg)** — Vertical/ground-plane omnidirectional donut pattern. Equal in all horizontal directions, low takeoff angle.
- **[G9-yagi-radiation-pattern.svg](G9-yagi-radiation-pattern.svg)** — 3-element Yagi-Uda directional pattern. Main lobe, back lobe, side lobes, element identification.
